Skill 库

所有实验 / 知识 skill 的标准 SKILL.md 文件，任何 agent 均可加载。skill 分两级：**pre-queue**（自写 / 生成后默认在此）与 **skill-queue**（已激活，可被 agent 调用）。选「调度到 skill-queue」把它激活；点「在资源管理器中显示」可在文件夹中定位文件。

回收站

模型与语音设置

只连接本机 HTTP 服务，不会自动切换云端。语言模型需单独启动；内置语音识别按需运行，不占用 GPU。

选择其他本地服务时，需支持 /audio/transcriptions。内置模式不使用该接口地址。回答朗读用 edge-tts 云端中文音色（需联网，文本经微软服务合成；首次需运行 setup-tts.ps1 安装依赖），失败时回退浏览器本地音。
