# 小红书图文 → OCR → 研习伴

本机流程：MediaCrawler 采集公开图文和 JSONL，已有 RapidOCR worker 将图片识别为 Markdown，再通过本地研习伴 API 导入。网页内的一键 OCR 入口仍未实现。

## 1. 采集

```powershell
$env:PLAYWRIGHT_BROWSERS_PATH='C:\Users\a1440\Desktop\MediaCrawler\.pw-browsers'
Set-Location 'C:\Users\a1440\Desktop\MediaCrawler'
.\.venv-mc\Scripts\python.exe main.py
```

目前的搜索实现仅采集图文，每个关键词最多 8 篇（读取现有 CRAWLER_MAX_NOTES_COUNT）。首页等待 domcontentloaded，导航和后续元素等待上限 90 秒。独立 Edge 档案保存登录状态；失效时需本人扫码。验证码/风控由本人处理，不自动绕过。不要同时运行两个采集任务。

- 图片：`MediaCrawler/data/xhs/media/{内容ID}/001.webp` 等。
- 元数据：`MediaCrawler/data/xhs/jsonl/search_contents_日期.jsonl`，含 `source_keyword`。
- 日志与 JSONL 可能包含平台会话相关链接，不应直接提交公开仓库。

## 2. OCR 和导入

确保研习伴在 `http://127.0.0.1:8765` 运行；已运行时不要再启动第二个共享 data/store.json 的进程。导入脚本本身不启动服务、不直接修改 store.json。

```powershell
Set-Location 'C:\Users\a1440\Desktop\Study companion'
# 只盘点，不 OCR、不写入资料
.\.venv-ocr\Scripts\python.exe scripts/import_xhs.py --dry-run
# 三个关键词全部处理
.\.venv-ocr\Scripts\python.exe scripts/import_xhs.py
# 可选：仅一个关键词，或用 --limit 1 验证首篇
.\.venv-ocr\Scripts\python.exe scripts/import_xhs.py --keywords 'PCR 实验'
```

脚本按关键词创建“小红书实验学习 · 关键词”笔记本。每篇资料包含原帖链接、内容 ID、图片目录、原帖正文和按图片编号的 OCR。Markdown 存于 `MediaCrawler/data/xhs/markdown/`；`*.ocr.md` 为识别缓存。

只处理 normal 图文、目标关键词和已有完整非空图片的目录；视频、未下载完的图片不导入。单篇失败会报告并继续其他篇，任何失败令进程返回非零。超过 200000 UTF-16 单元的正文拒绝导入，须另行拆分。

同一笔记本中，内容 ID 与图片内容哈希一致时跳过，重复运行不会重复导入；图片改变会生成新的资料版本，旧资料保留。图片不变但原帖正文改变时，当前不会自动更新既有资料。不要并行运行多个导入脚本。

## 3. 学习与核对

在左侧选择对应笔记本 → 学习资料 → 查看原文/校对文稿；在“共读笔记”点击“从资料整理”，或在右侧提问。生成的草稿保留在对话中，确认后才“追加到笔记”。

OCR 对上下标、数字和单位会误识别，必须对照原图；采集结果按关键词匹配，未逐篇确认实验适用性。共读目前有上下文预算限制，出现截断提示时，答案只基于选中的部分证据；成功生成草稿不等于完整审阅全部图片，也不代表规程已经验证。
