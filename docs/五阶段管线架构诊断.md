# 五阶段管线架构诊断与验收边界

## 旧入口与缺陷

| 入口 | 已定位缺陷 | 替代路径 |
|---|---|---|
| scripts/visual_review.py subtitle_rows / slide_rows / main | 上下区域等同于字幕/课件，RawMultimodalDocument.visual_description混装OCR与VLM | typed evidence，图像分类有预算；未知区域保留UNKNOWN，不伪称课件 |
| server.mjs evidence() | 聚合字符串丢失模态与置信度来源 | EvidenceItem不可变raw_text与稳定ID |
| server.mjs generateNote()/summarize() | 各批Markdown直接拼接，没有事实模型、全局冲突检测 | AtomicFactCard Map、全局聚类Reduce、显式ConflictRecord |
| src/distiller/prompts.txt | 不确定性仅靠提示词，无可执行准入条件 | auditor审计状态与renderer确定性分层 |
| server.mjs /api/quiz 与 src/deeptutor/quiz.mjs parseQuiz | 直接使用原始/OCR文本；原句匹配被当作答案质量保证 | 仅CORE事实白名单，盲解器独立上下文，不见答案/解析/转写 |

## 协议

Pydantic模型见 src/schemas/pipeline.py：EvidenceItem、AtomicFactCard、ConflictRecord、AttributionAuditResult、VerifiedQuizItem、PipelineArtifact。时间统一秒，UI引用转换成毫秒。未知模态新增UNKNOWN_VISUAL_OCR；普通文本新增DOCUMENT_TEXT，避免强行标注为ASR。提取置信度不等于真实性。

术语自举只生成CANDIDATE_ONLY映射，禁止修改原句。画面语义分类只使用真实图像；没有图像或未分类预算外画面保留未知。UI数字即使与语音数值相同，也不能单独证明语义对应，必须审计后才能作为特定情境证据。

三源归因允许UNDETERMINED，不强迫模型选择错误责任。ASR/字幕一致只能证明材料一致，不能证明学科正确或主讲人过错。缺少外部规范时，审计模型的边界建议必须标为模型审阅；不能捏造外部标准。

盲解独立的是上下文，不保证不同模型权重。当前同一服务时必须标记shared-model blind contexts；一致性不等于外部事实认证。没有合格核心事实时返回无题，不退回原始资料出题。

## 验收

跨领域测试覆盖软件配置/物理单位/通用演示数据；领域术语不得硬编码。验证噪声隔离、未对齐读数封锁、来源错误与总结错误区分、同对象不同条件不误合并、冲突不隐藏、题库黑名单与答案泄漏检查、材料变更失效。真实课程重跑报告单独记录，不将mock测试称作真实质量验收。

## 本次实现的明确边界

- 实际视觉分类有每次6帧预算，预算之外标未知；当前仪器读数全部保守排除，不宣称已实现完整的读数语义对齐引用。
- 术语自举提供候选而不是自动替换。来源一致不等于学科正确；独立反例审查会继续降级缺少条件的核心候选。
- 每批最多6张高价值卡片，因此全文输入覆盖不等于知识点穷尽覆盖。真实课程无冲突检出不等于不存在冲突。
- 结果ID取整个审计产物的内容哈希。相同资料产生不同审计结果时，旧题不会继续适用于新版本。
- 三源归因原始意见、重写前后与复审结果在audit.json；最终归因在artifact.json。引用不成立的提取候选在map-reduce.json留档，不进入正文。
- 可复现报告：scripts/report_pipeline.py --run-dir <data/pipeline-v2/结果ID> --output <报告路径>。
