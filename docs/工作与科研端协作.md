## T60运行与接入方式

首阶段提供可运行的业务模块和命令行，尚无新的网页按钮。输入是已有五阶段管线导出的artifact.json，不能直接把视频/PDF文件当作输入；前置导入、转写、OCR和审计仍使用原项目流程。

在Windows PowerShell的项目根目录，科研合成演示可执行：

```powershell
node scripts/research-report.mjs --artifact tests/fixtures/research-notes/artifact.json --outline tests/fixtures/research-notes/outline.json --out ../research-demo-01
```

运行后应打印报告ID及4条来源要点、4条待核对，并在新目录中生成report.json和report.md。目录已存在时明确拒绝覆盖；重跑请换新目录。读入和校验失败不产出报告，写入中断会清理本次新建的报告文件；不删除其他文件。

报告/会议模板：

```powershell
node scripts/research-report.mjs --artifact tests/fixtures/research-notes/artifact.json --template meeting --out ../meeting-demo-01
```

科研栏目映射是“栏目id→已有事实id数组”：research_question、methods、results、limitations、discussion、topics；没有映射的来源要点进入topics。会议模板只用topics。不能映射到decisions/action_items，也不能用映射让待核对事实进入正文。映射只是人工组织位置，不是新的语义核验。

现成产出：[科研报告演示](../evaluation/research-notes/research-demo/report.md)、[报告/会议演示](../evaluation/research-notes/meeting-demo/report.md)、[样例说明与复算方式](../evaluation/research-notes/README.md)。这些文件明确标记合成样例；不存在对应的真实录音可供播放。JSON保留来源/媒体ID与毫秒时间，应用内证据跳转由T61接入原有回看交互。

T61已把buildResearchReport和renderResearchReport接入网页。接口只读，不写原PipelineArtifact，不产生新的模型事实，不把原审计状态升级为科学认证；网页API与版本保存约定见下文。

业务模块入口是buildResearchReport(artifact, {template, outline})，渲染入口是renderResearchReport(report)。返回值中的sections.items是原来源陈述；pending保留隔离原因与候选用于复核；evidence_index保留引用定位。source_pipeline_id绑定原管线，report_id随输入/编排内容确定性变化；decisions、action_items首阶段固定为空。调用者不能把source_items计数解释为已确认决议数或准确率。

全局契约错误（未知版本、重复事实/证据ID、无效冲突引用、错误栏目映射）显式失败；单条事实的审计、引用、风险或时间问题进入pending。CLI成功退出0，参数/输入/写入失败退出1；输出目录已有时保留原文件。原时间秒转换为毫秒，无时间就保持null，不创造可播放定位。

## T61网页入口与保存契约

在原笔记本页签选择“科研报告”，先完成“从资料整理”五阶段审计，再选“科研报告”或“报告／会议材料”模板。网页调用`GET /api/research/report?notebookId=<id>&template=research|meeting`，只从当前审计产物返回报告JSON与Markdown；没有审计产物或资料已变化时拒绝生成，并提示重新审计。失败时生成按钮可再次请求。

每条报告陈述和待核对候选提供原句回看按钮，复用学习端现有来源/媒体定位；只有已有毫秒时间且笔记本中媒体记录可用时才尝试播放。页面支持下载Markdown/JSON。

保存调用`POST /api/research/report/save`，服务端重新编排当前审计结果，不接受客户端上传改写后的报告正文。报告作为独立revision保存，记录模板、报告ID、来源管线ID、输入哈希、报告JSON与Markdown。同一管线和模板重复保存复用同一版本；学习端笔记、聊天和Skill的最新笔记读取不把科研版本当作学习笔记，旧学习笔记保持不变。

## T62真实材料验收工具与阻塞

记录模板为[real-evaluation.template.json](../evaluation/research-notes/real-evaluation.template.json)，使用方法见[真实材料验收说明](../evaluation/research-notes/T62-真实材料验收说明.md)。`scripts/evaluate-research-notes.mjs`只读取人工填写的验收记录并汇总；它不调用模型、不读取模型密钥、不上传材料。`REAL`记录必须登记已授权且非合成的SHA-256材料、开发集与留出集、服务商/模型版本、文献分享与组会或培训留出样本，以及逐例人工判断和复核。
