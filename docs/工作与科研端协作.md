## T60验收标准

1. 支持科研与报告/会议两种输出结构；没有材料依据的结论、共同决议、行动项、责任人、截止日期和文献元数据保持待确认，不自动填造。
2. 来源要点仅来自已有审计通过、非冲突且引用可核对的事实；未经审计、错误引用、不明视觉和高风险条目保留为待核对。栏目映射只调整组织位置，不改写事实或改变其证据等级。
3. 每条保留事实ID、证据原句、来源ID、媒体ID、页/段位置（已有时）和原时间区间。不同媒体不拼成连续证据；时间定位沿用项目毫秒单位。
4. 原始事实、输入文件、原管线产物、人工修改与用户学习库都不覆盖；CLI只写显式指定的新输出目录，重复运行结果可比对。
5. 无网络和模型依赖；覆盖有效资料、缺字段、错误/缺失引用、冲突/未核实、低可信画面、不同媒体、恶意Markdown内容和重复运行。专项与原项目Node回归、Python契约、JS语法通过。

“来源审阅通过”只表示沿用原管线检查，不代表外部科学核验。首阶段没有自动将陈述识别为团队决议的能力；需要T61/T62中的人工确认与实测，不能用字符串匹配或单元测试代替语义正确性。

## T60运行与接入方式

首阶段提供可运行的业务模块和命令行，尚无新的网页按钮。输入是已有五阶段管线导出的artifact.json，不能直接把视频/PDF文件当作输入；前置导入、转写、OCR和审计仍使用原项目流程。

在Windows PowerShell的项目根目录，科研合成演示可执行：

```powershell
node scripts/research-report.mjs --artifact tests/fixtures/research-notes/artifact.json --outline tests/fixtures/research-notes/outline.json --out ../research-demo-01
```

运行后应打印报告ID及4条来源要点、4条待核对，并在新目录中生成report.json和report.md。目录已存在时明确拒绝覆盖；重跑请换新目录。读入和校验失败不产出报告，写入中断会清理本次新建的报告文件；不删除其他文件。

报告/会议模板：

```powershell
node scripts/research-report.mjs --artifact tests/fixtures/research-notes/artifact.json --template meeting --out ../meeting-demo-01
```

科研栏目映射是“栏目id→已有事实id数组”：research_question、methods、results、limitations、discussion、topics；没有映射的来源要点进入topics。会议模板只用topics。不能映射到decisions/action_items，也不能用映射让待核对事实进入正文。映射只是人工组织位置，不是新的语义核验。

现成产出：[科研报告演示](../evaluation/research-notes/research-demo/report.md)、[报告/会议演示](../evaluation/research-notes/meeting-demo/report.md)、[样例说明与复算方式](../evaluation/research-notes/README.md)。这些文件明确标记合成样例；不存在对应的真实录音可供播放。JSON保留来源/媒体ID与毫秒时间，真正的应用内跳转由T61接入原有回看交互。

后续T61可以调用buildResearchReport和renderResearchReport。接口只读，不写原PipelineArtifact，不产生新的模型事实，不把原审计状态升级为科学认证；公共API/保存契约在T61单独协调。

业务模块入口是buildResearchReport(artifact, {template, outline})，渲染入口是renderResearchReport(report)。返回值中的sections.items是原来源陈述；pending保留隔离原因与候选用于复核；evidence_index保留引用定位。source_pipeline_id绑定原管线，report_id随输入/编排内容确定性变化；decisions、action_items首阶段固定为空。调用者不能把source_items计数解释为已确认决议数或准确率。

全局契约错误（未知版本、重复事实/证据ID、无效冲突引用、错误栏目映射）显式失败；单条事实的审计、引用、风险或时间问题进入pending。CLI成功退出0，参数/输入/写入失败退出1；输出目录已有时保留原文件。原时间秒转换为毫秒，无时间就保持null，不创造可播放定位。
