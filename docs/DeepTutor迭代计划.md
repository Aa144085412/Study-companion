## 2026-10-20 第二轮实现
- 全文证据分批进入笔记与 Skill 生成，不再静默截掉尾部；连续字幕合并后检索，支持“最后/结尾”时间定位。
- 逐题伴学：独立提示词、问题来源、回答反馈、掌握度、版本冲突控制；学习状态随笔记本备份/回收站保存。
- 视觉核对：本地 MP4/WebM → 逐条转写中点抽帧 → 画面下部字幕候选 + 上部课件/界面正文候选 → 本地视觉回退（每次最多8帧）。这是区域启发式，不是已人工校对字幕或保证完成的场景分割。
- 新需求：联合课件/PPT、讲解与字幕提高笔记质量。全文OCR区分区域，按文字变化组织画面，数字变化不去重；生成独立联合证据 SRT 并链接视频，保留原ASR，不自动替换原稿。无字幕不等于无画面信息。
- 提示词明确区分OCR候选、原始语音和视觉推断，忽略水印，无依据参数不补猜。公式/图表关系需要视觉确认，低分辨率未读清不作事实。
- Skill：分批生成+独立提示词，导出 skills/<name>/SKILL.md 与 references/course.md、notes.md、sources.json，兼容旧的单文件库。强制生成失败保留旧文件。
- 验证：Node 61项、Python契约8项+视觉4项；实际视频379个抽样帧的第一轮字幕核对完成（341帧字幕候选、8帧视觉推断、30帧待核对）。第二轮已完成：379帧、365帧画面正文、341帧字幕候选、16帧视觉输出、29帧无字幕和视觉输出；统一多模态JSON及SRT已生成。
- 真实LLM：已生成基础概念首题；末尾检索可找到1450–1545秒原转写，但原ASR错字多，因此不能仅凭文字认定软件名。
- 限制：不是外部DeepTutor项目的集成；本版为研习伴内置伴学。AI评分未做大规模人工标定，多选题型尚未增加；当前每轮为开放式概念/参数/排错题。全文处理不等于模型准确理解，分批摘要尚无全局去重整合。
