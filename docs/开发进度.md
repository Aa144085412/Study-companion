## 2026-10-09 · 自然中文朗读（Kokoro-ONNX，纯 CPU，不占显存）

此前「朗读」走浏览器 Web Speech API，最终落到操作系统内置本地音（Windows Huihui），机器感重、难听。评估过 GPT-SoVITS 克隆"本人声音"（质量天花板），但它合成时占用 5090 显存（~1–2GB），用户拍板放弃克隆、只要一个自然点的声音且**不占显存** → 选 **Kokoro-82M（ONNX int8）**：82M 参数、**纯 CPU（ONNX Runtime，无 PyTorch/无显存）**、Apache-2.0、离线、自然中文音色，模型 ~85MB + 音色 ~28MB，输出 24kHz WAV。

- **架构（复用 ASR 一次性 worker 模式）**：`tts.mjs` spawn `.venv-tts\Scripts\python.exe tts_worker.py <文本文件> --out <wav> [--voice]`，stdout 走 JSON-lines（`loading`/`result{file,sampleRate,voice}`/`error`），`PYTHONIOENCODING=utf-8`、`windowsHide`、120s 超时、AbortController。Kokoro 加载仅 1–2s，故沿用"每次新建进程"而非常驻（零常驻、零显存），与 `asr_worker.py` 同构。
- **接口**：新增 `POST /api/tts`（body `{text}`，trim 后空→400、>2000 字→413，回传 `audio/wav` 字节）；`GET /api/health` 加 `tts:ttsStatus()`；`db.settings.ttsVoice` 默认 `zf_xiaobei`，`POST /api/settings` 可改。
- **前端**：`speak(value)`（[app.js](public/app.js) 单一朗读接缝）改为先 `POST /api/tts` 拿 WAV blob 播放，未安装/失败时**回退**原 `speechSynthesis` 本地音（不阻断）；`stopSpeak()` 统一停 `Audio` + `speechSynthesis.cancel()`，「停止」按钮改绑 `stopSpeak`。设置弹窗新增「朗读音色（本地 Kokoro·中文）」下拉（4 女 `zf_*` / 4 男 `zm_*`）。
- **中文音色的 espeak lang 码 = `cmn`**（非 `zh`，espeak backend 拒绝 `zh`），已在 worker 固定。
- **安装**：`setup-tts.ps1`（`uv venv --python 3.10 .venv-tts`，`uv pip install kokoro-onnx soundfile`，缺则下载模型/音色，跑一次合成自检，写 `.venv-tts/tts-ready.flag`）。**坑**：.ps1 里含中文会被 Windows PowerShell 5.1 按 GBK 误读破坏解析 → 脚本改纯 ASCII，自检文本用英文（合成内容不影响链路验证）。
- **活体验证中修的一处确定性 bug**：`ttsStatus()` 只返回 `{ready,engine,device,message}` 却漏了 `python` 路径，`synthesize` 里 `spawn(status.python)` 收到 `undefined` → `spawn` 抛 `The "file" argument must be of type string`（此 "file" 指 spawn 的可执行文件，非音频 `result.file`，极易误判）。修复=`ttsStatus()` 返回体补 `python`（对齐 `asrStatus()`）。
- **验证**：`npm test` 11/11（含 3 项 TTS：`/api/tts` 回 `audio/wav` 非空、空/超长 400/413、`ttsStatus` 形状）；活体 `POST /api/tts` 回 200 合法 WAV（RIFF PCM 16-bit mono 24kHz，~445KB）；浏览器实测 `speak()`→`POST /api/tts` 200→blob 206→`<audio>` 播放、`stopSpeak()` 正常、音色下拉 8 项就位、控制台无报错。
- **边界（如实）**：固定预置音色，**非"本人声音"克隆**；每次朗读为一次性进程（含 ~1–2s 模型加载），长文按整段合成（当前不做逐句流式）；`/api/tts` 上限 2000 字。
