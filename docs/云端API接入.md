# 云端 API 接入：没有本地模型时如何使用研习伴

适用分支：codex/cloud-api-onboarding。当前已完成兼容接口的程序实现与模拟回归；尚未选定云端服务商，也没有真实服务商密钥，因此不能把本文称为真实云端课程验收。

## 先明确运行方式

研习伴仍在你的电脑运行 Node.js 服务，通过浏览器访问本机页面；语言模型和语音识别可以由你选择的云端 API 执行。无需先在本机部署大语言模型。GitHub 仓库页面用于协作和保存源码，不是应用运行页面。

这里的 API 地址是服务商文档提供的程序接口基础地址，不是聊天网站的网址。接入前需要取得基础地址、模型 ID 和 API 密钥。服务商未选定时，不预填某个收费平台，也不虚构可用模型名。本文的 provider.example / speech.example 都是示例占位地址，不能用于真实请求。

## 最小启动路径（Windows PowerShell）

需要 Git、Node.js 22+ 和 Python 3.10+。Python 用于校验笔记审计数据的格式，不等于部署本地 AI 模型。

代码已在本地时，进入项目目录，先安装最小校验环境：

```powershell
.\setup-course.ps1
```

应看到 Validation ready 和 No local AI model was downloaded。脚本只在项目 .venv-ocr 中安装 requirements-course.txt 的 Pydantic 数据校验依赖；不会下载语言、语音或 OCR 模型，也不会自动安装完整 OCR 工具链。

然后启动应用：

```powershell
node server.mjs
```

在浏览器打开 http://127.0.0.1:8765。需要与另一副本同机运行时，为该副本设置不同 PORT，且保持 data 目录独立。端口占用时先确认已有服务归属，不擅自停止用户任务。

## 配置语言模型

1. 在研习伴页面点击左下角“模型与语音设置”。连接方式选择“云端 HTTPS API · 兼容 OpenAI 格式”。
2. 在“API 基础地址”填写服务商给出的基础地址，通常包含 /v1，具体以其文档为准。不要附加 /chat/completions、/models 或密钥参数。
3. 在“模型名称”填写准确的模型 ID，在“API 密钥”中填写该服务商密钥。模型是否可用由你的服务商账号权限决定。
4. 点击“保存并测试文本生成”。程序发送一条简短连接请求；应看到“文本生成连接测试通过”。该结果只证明本次文本请求成功，不代表图片、工具调用、长课程准确性均已验收。
5. 服务支持模型列表时，也可点击“保存并读取模型列表”。不支持 /models 时，手动填写模型名后做文本测试即可，不会因为缺少列表而阻止使用。

保存后，密钥输入框清空，但显示“本机已保存密钥”。留空再次保存会保留原密钥；更换 API 地址后需要重新填写，避免把旧服务商的密钥发送给新地址。“清除本机保存的语言模型密钥”会删除该项本机密钥。

先用 TXT、Markdown 或 SRT 导入一份简短资料，尝试文字共读，再运行“从资料整理”和逐题伴学。长课程会进行多次提取与审查请求；连接测试成功后仍应从小材料开始确认兼容性。

## 配置语音识别

语言模型与语音识别是两种接口。语言模型密钥不能自动证明同一服务商支持语音，也不默认复用到语音服务。

1. “识别方式”选择“外部识别 API · 本地或云端”；“外部接口位置”选择“云端 HTTPS API”。
2. 分别填写外部识别 API 基础地址、识别模型名称和语音识别 API 密钥。
3. 点击“保存并检查识别配置”。显示“已配置”只证明配置和密钥存在，尚未发送真实语音；用一小段录音或音频执行一次识别后，才算确认该服务能完成转写。
4. 语音提问只要求返回 text。媒体“转成文字”和 agent 转写工具还要求支持 verbose_json、timestamp_granularities[]=segment，并返回分段 start/end 秒级时间戳。程序会转换成项目使用的毫秒并关联原媒体。

本应用将外部识别限制为每文件 25 MB，服务商还可能有更小限制。原始媒体仍允许导入至 250 MB，但较大文件不能直接交给外部识别；应先拆分音轨，或导入已有 SRT。没有有效时间戳时，媒体任务会明确失败，不编造时间戳、不伪称视频溯源已完成。

## 图片、课件与其他功能边界

云端图片发送默认关闭。只有模型支持 image_url 图片输入、且你勾选“云端模型支持图片，允许发送来源原图和视频抽帧”后，才允许共读原图、画面分类和视觉补充请求发送图片。门禁在统一服务端请求入口执行，其他调用路径不能绕过这一设置。

视频画面 OCR 仍依赖本机 ffmpeg、Pillow、RapidOCR 等工具；配置云端语言模型不会自动安装这些组件。Python 视觉补充经本机网关调用所选模型，API 密钥不会写入 Python 任务的 input.json。旧历史视觉任务配置保持历史状态，本次不重写已有产物。

“实验 Agent”的函数调用编排需要服务商模型支持 Chat Completions 的 tools/tool_calls 格式。纯文本生成成功并不能证明这一能力。微信公众号、小红书及视频下载仍受各自工具、登录态和网络条件限制，不能宣称一次 API 配置就打通全部采集流程。

朗读仍使用现有 edge-tts 云端路径，需要另行运行 setup-tts.ps1 并准备 ffmpeg；失败时回退浏览器本地音。选择语言模型不会更换朗读服务。

## 密钥、数据与接口协议

浏览器只向本机研习伴服务提交配置和任务，由服务端调用所选 API。文字任务发送相关资料和问题；语音任务发送所选音频；获准的图片任务发送相关原图或抽帧。不会自动切换服务商。

API 密钥与笔记数据分开，保存在被 Git 忽略的 data/api-secrets.json；应用状态接口与笔记备份不返回密钥。该文件是本机明文配置，不是系统保险库，能读取本机数据目录的人仍可读取。迁移笔记备份后应重新配置密钥；手动复制整个 data 目录时也会包含密钥文件。

管理员可在服务端设置 STUDY_LLM_API_KEY、STUDY_ASR_API_KEY 环境变量覆盖本机保存值。状态显示密钥来源；清除本机值不会移除环境变量。这里只使用这两个项目专用变量，不自动读取其他软件的密钥或自动加载 .env。

程序使用 Bearer 鉴权和以下兼容路径：

| 功能 | 路径 / 返回要求 |
|---|---|
| 文字生成与审计 | POST /chat/completions，choices[0].message.content 为文字或 JSON 字符串 |
| 模型列表（可选） | GET /models，data[].id |
| 语音提问 | POST /audio/transcriptions，multipart/form-data，返回 text |
| 媒体溯源转写 | 同一转写路径，verbose_json + 分段秒级时间戳 |
| 图片 | Chat Completions 的 image_url 输入；需明确开启 |
| 工具编排 | Chat Completions 的 tools/tool_calls；需模型支持 |

云端请求会移除本地推理服务专用的 chat_template_kwargs。不同服务商对 temperature、max_tokens、JSON 输出、工具调用和音频格式支持可能不同，本文不承诺所有兼容平台或所有模型都能完成整条管线。仅提供 Responses、原生 Anthropic/Gemini 等其他协议的地址不能直接使用本适配器。

标准格式参考 [OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create) 与 [Audio Transcriptions](https://developers.openai.com/api/reference/resources/audio/subresources/transcriptions/methods/create)。第三方服务的实际字段支持、限额与模型名称以该服务商官方文档为准。

## 常见结果与下一位执行者的验收

HTTP 401/403：核对密钥、服务地址与模型权限。HTTP 429：查看服务商配额或频率限制。HTTP 400 或其他错误：确认模型、协议和参数兼容性。程序不将服务商错误正文直接回传到页面，以免暴露密钥或其他内部信息。

下一位选定服务商后，依次保存配置、测试文本生成、导入小材料并核对笔记和题目，再分别验证短语音、带时间戳媒体、图片和工具编排。每一步在阶段记录中写明服务商、模型、时间、实际结果和未覆盖项，不记录真实密钥，不把模拟接口的结果当真实模型质量证据。
