## T47 实际改动

- 笔记引用显示时间，点击后右侧共读区切换为证据核对区；笔记仍可阅读。
- 核对区展示保存的原句、时间范围、原视频、重播、前后各 10 秒、完整原文及返回入口。
- 优先使用引用本身的媒体 ID，避免来源后来重新关联造成历史引用播放错视频。旧引用没有媒体 ID 时才使用来源关联。
- 来源缺失仍显示保留的引文，但提示不能确认；无可靠时间戳不自动跳到 0 秒冒充定位。
- 新生成笔记保留证据类型。历史笔记未记录类型时明确显示“历史引用”，本轮没有猜测或覆写历史类型。
- 继续保留本地视频导入。没有直接修改 store.json、重新生成现有笔记或改变用户答题记录。
