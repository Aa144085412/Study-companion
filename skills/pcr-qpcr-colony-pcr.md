# PCR / qPCR / 菌落 PCR 实验操作

## 目标
掌握 PCR 基本原理、常规 PCR 体系配制与程序设置，并了解 qPCR / RT-qPCR 和菌落 PCR 的用途。

## 材料
- 模板 DNA
- 引物
- dNTPs 混合液
- DNA 聚合酶 / Taq 酶
- PCR buffer
- H₂O
- Mg²⁺
- DNA marker
- DNA 上样缓冲液
- 琼脂糖
- TAE buffer / agarose buffer
- 裂解液

## 步骤
### 1. 准备模板 DNA
- 操作：根据实验目的和样本类型选择或提取模板 DNA，用于 PCR 扩增。
- 参数：提取方法可包括酚/氯仿法、柱式法、磁珠法、煮沸法；具体体积、浓度待核对。
- 注意：模板 DNA 质量应良好、浓度适中，否则可能影响扩增效率。
- 检查点：材料未说明具体检测方法，待核对。

### 2. 设计或选择引物
- 操作：设计或选择正向引物和反向引物，使其分别与目标 DNA 两端互补。
- 参数：引物长度通常为 18–30 bp；GC 含量 40%–60%；Tm 值一般控制在 55–65℃；退火温度常参考 Tm − 5℃。
- 注意：引物过短会降低特异性，过长会增加退火温度并影响结合效率；GC 含量过低会导致结合不稳定；避免引物自身形成发夹结构或引物二聚体；3′ 端最后几个碱基宜为 G 或 C，避免 3′ 端错配。
- 检查点：正向和反向引物 Tm 值应尽量接近；引物无明显二级结构或二聚体风险。

### 3. 配制 PCR 反应体系
- 操作：加入模板 DNA、引物、dNTPs 混合液、DNA 聚合酶 / Taq 酶、PCR buffer、H₂O 和 Mg²⁺。
- 参数：各组分具体体积、浓度待核对；部分 PCR buffer 可能已预混 Mg²⁺，需根据试剂说明判断是否单独加入 Mg²⁺。
- 注意：PCR buffer 用于维持适宜 pH 和离子强度；Taq 酶最适 pH 范围为 8.3–9.0。
- 检查点：材料未说明具体加样顺序和体积，待核对。

### 4. 设置 PCR 程序
- 操作：设置变性、退火、延伸循环程序。
- 参数：变性温度 94–98℃，材料图片中具体写为 94–95℃；退火温度通常 50–65℃，取决于引物 Tm 值；延伸温度 72℃；常见循环数 25–35 个循环。
- 注意：退火温度需根据引物 Tm 值设定；延伸温度 72℃ 为 Taq 酶最适活性温度。
- 检查点：材料未说明具体程序时间，待核对。

### 5. 电泳检测扩增产物
- 操作：使用琼脂糖凝胶电泳检测 PCR 扩增产物，并用 DNA marker 判断片段大小。
- 参数：凝胶浓度、电泳电压、电泳时间、上样体积待核对。
- 注意：需使用 DNA 上样缓冲液和 TAE buffer / agarose buffer 制备或电泳体系。
- 检查点：电泳后应可见预期大小的 DNA 条带；具体判断标准材料未说明，待核对。
