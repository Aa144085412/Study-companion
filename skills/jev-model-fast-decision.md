# JEV 模型快速决策原理

## 概览
JEV 模型通过外部程序提供当前页面可选项，一次性计算各选项与当前状态的得分并用 softmax 输出概率，从而避免大语言模型自回归逐词生成，适合快速决策。

## 何时不要用
- 需要具体实验参数、训练配置、性能倍数或基准测试时：材料未说明，待核对。
- 需要长文本生成、复杂逻辑推演、写作或代码生成等“慢思考”任务时：材料未证明 JEV 可替代大语言模型。
- 需要确认 JSON 字段、读取频率、延迟或 softmax 实现细节时：材料未说明，待核对。

## 核心要点（先看这里）
- 大语言模型做决策时通常需要自回归：每生成一个新词，都要将前面生成的结果重新打包输入，因此只能逐词输出。
- 大语言模型每次输出时，会把计算结果硬设成固定大小的词表长度，再用 softmax 计算每个词的概率，最后选择概率最高的词输出。
- JEV 模型不逐词生成，而是计算每个可选项与当前状态的得分，再用 softmax 将这些得分转化为每个选项的概率。
- JEV 模型的选项概率是一次性输出的，因此一次计算就能根据当前状态做出决策。
- 可选项信息主要由外部程序自动抓取：程序后台读取页面状态、爬取可点击按钮，并组装成结构化 JSON 文档发给 JEV 模型。

## 关键概念与名词
- JEV 模型：材料中用于快速决策的模型，通过一次性输出选项概率做决策。
- 大语言模型：通过自回归逐词生成文本的模型。
- 自回归：每生成一个新词时，需要把前面生成的结果重新打包输入的过程。
- softmax：将得分或计算结果转化为概率分布的函数。
- 词表长度：大语言模型输出时固定大小的候选词表长度；具体数值待核对。
- 结构化 JSON 文档：外部程序抓取页面可选项后组装并发送给 JEV 模型的文档；字段和格式待核对。
- 快思考 / 慢思考：材料引用《思考，快与慢》的理念，将 JEV 模型类比为快思考，将传统大语言模型类比为慢思考。

## 知识要点（分主题）
### 大语言模型的速度瓶颈
- 大语言模型做决策时通常需要自回归生成。
- 每生成一个新词，都需要将前面生成的结果重新打包输入。
- 每次输出时，大语言模型会把计算结果硬设成固定大小的词表长度。
- 大语言模型用 softmax 计算每个词的输出概率，并选择概率最高的词输出。
- 因此大语言模型只能一个词一个词地输出，在需要快速决策的任务中效率较低。

### JEV 模型的输出机制
- JEV 模型不需要计算每个词的概率。
- JEV 模型计算每个可选项与当前状态的得分。
- JEV 模型将这些得分用 softmax 转化成每个选项的概率。
- 这些概率是一次性输出的。
- JEV 模型一次计算就能根据当前状态做出决策。
- JEV 模型一次输出即可做出一个决策，并用外部程序判断决策的准确性。

### 外部程序提供可选项
- JEV 模型的可选项信息大部分由程序自动抓取提供。
- 该程序可以后台实时读取电脑页面状态。
- 该程序可以爬取页面上可点击的按钮。
- 该程序将信息组装成结构化 JSON 文档。
- JSON 文档被发送给 JEV 模型。
- 程序的读取频率、延迟、采样间隔、JSON 字段和格式待核对。

### 快思考与慢思考定位
- JEV 架构参考了《思考，快与慢》中的理念。
- 传统大语言模型代表慢思考，擅长逻辑推演、写作、代码等任务。
- JEV 模型代表快思考，更擅长快速直觉判断。
- 材料认为未来两种系统的相互结合，或许才是 AI 的进化方向。

## 方法 / 流程（若有可操作步骤）
1. 程序后台实时读取电脑页面状态。
2. 程序爬取页面上可点击的按钮。
3. 程序将信息组装成结构化 JSON 文档。
4. JSON 文档发送给 JEV 模型。
5. JEV 模型计算每个可选项与当前状态的得分。
6. JEV 模型用 softmax 将得分转化为每个选项的概率。
7. JEV 模型一次性输出决策。
8. 外部程序判断决策的准确性。

注意：以上流程来自材料对模型工作过程的描述，不能直接当作已确认的实验操作规程。
