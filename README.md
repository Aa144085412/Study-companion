# 研习伴 · Study Companion

从记录到理解，从理解到实践。

这是独立开发的 **v0.1 开发预览版**，用于验证资料、笔记和 AI 共读流程。尚未达到计划书中全部 P0 的交付标准，也尚未接入科研工作台。

## 启动

需要 Node.js 22 或更新版本，无需 npm 安装依赖。

双击 `启动研习伴.vbs`，或在项目目录执行：

```powershell
node server.mjs
```

浏览器访问 http://127.0.0.1:8765。服务只监听本机。启动器隐藏启动服务以避免终端反复弹窗，日志写入 `data/server.log`。关闭页面不会结束服务；使用 `停止研习伴.ps1` 停止由启动器记录的项目进程。

## 当前已实现

- 笔记本创建；TXT、Markdown、SRT 导入；媒体上传与播放。
- 笔记编辑与版本保留，历史版本载入编辑区，Markdown 导出。
- SRT 分段时间戳、关联原媒体、点击时间或回答引用播放片段。
- 本地模型接口设置、模型检测、资料生成笔记草稿。
- 选中笔记文字后提问、多轮对话、来源引用标识校验。
- 疑问清单与状态管理。
- 按住录音，调用本地识别接口，识别结果可编辑后发送。
- 浏览器本地中文语音朗读（取决于系统是否有本地中文语音）。

## 第一次使用

1. 左侧 ＋ 创建笔记本。
2. 在学习资料导入文稿或字幕；需要回放时同时导入媒体，并在字幕卡片选择关联文件。
3. 编辑并保存笔记。也可在配置好模型后点击“从资料整理”，预览草稿再追加到笔记。
4. 在模型设置中填写正在运行的本地语言模型地址和模型 ID；可保存并检测模型。
5. 选中文字，输入问题或按住说话。语音服务需另外启动并配置。
6. 回答中点击来源核对。加入笔记只修改编辑区，需再次保存版本。

## 模型接口

语言模型默认指向 `http://127.0.0.1:1234/v1`，支持 `/models` 和 `/chat/completions`。语音识别默认占位地址为 `http://127.0.0.1:8000/v1`，需实现 `/audio/transcriptions`，返回 `{"text":"..."}`。地址和模型名可修改。

本项目不自动安装、加载或下载模型，也不会从本地服务回退到云端。接口仅接受本机 HTTP 地址，禁止重定向。仅连接本机不保证该本机服务自身不代理云端：用户还应检查所选服务配置。

## 限制与后续开发

- 单个媒体文件最多 32 MB；当前用于回放，没有长音视频自动转写任务队列。先用 Buzz 导出 SRT 再导入。
- 文本入口限制 500 KB，后端拒绝超过 200,000 字符的资料或笔记；请将长文稿拆分。
- 当前来源上下文按导入顺序选取，预算 30,000 字符，单段最多 5,000 字符；不是完整向量检索。超长材料建议拆分。
- 引用标识会检查是否存在，但不能自动保证模型结论受到引用支持，仍需人工核对。
- 尚未接入转写校对版本、段落级笔记证据映射、PDF/OCR、自动复述练习、连续语音、可视化备份恢复。
- 文件备份：停止服务后复制整个 `data` 文件夹。恢复时停止服务，用备份恢复 `data`；不要只复制 store.json 而漏掉媒体。
- 第一版面向个人本机使用，不面向局域网公开访问。
- 本地识别和语言模型实际效果需要真实模型联调；自动测试使用模拟模型，不是识别准确率证明。
