## 启动与停止

需要 Node.js 22+；Node 服务无第三方 npm 运行时依赖。

- 双击 `启动研习伴.vbs`，浏览器访问 `http://127.0.0.1:8765`。
- 或在项目目录运行 `node server.mjs`。
- 停止使用 `停止研习伴.ps1`；维护重启使用 `restart.ps1`，先确认没有正在进行的用户任务。
- 服务仅监听本机；关闭网页不等于停止服务。不要同时启动两个进程共享 `data/store.json`。
- 2026-10-10 核对时 8765 连接被拒绝，服务未运行；此状态只是当时快照。

## 当前功能

| 功能 | 实现与边界 |
|---|---|
| 资料导入 | TXT、Markdown、SRT；MP3/WAV/M4A/MP4/WebM/OGG 媒体流式上传 ≤250 MB，并做同笔记本文件哈希去重 |
| 转写 | faster-whisper-small、CPU int8、OpenCC 繁转简；排队、取消、重试；重启后活动任务标为 interrupted，重试从头开始 |
| 校对 | 保留原文与时间戳，校对生成新版本 |
| 笔记 | 编辑、历史版本、生成草稿、Markdown 导出 |
| 共读 | 选段问答、短多轮上下文、引用标识校验及媒体回放 |
| 语音提问 | 按住录音、设备选择、录音文件提问、识别后编辑、取消与权限帮助 |
| 朗读 | edge-tts 中文云端音色；朗读前去除常见 Markdown 符号；失败回退浏览器本地音 |
| 实验指导 | 从笔记生成 `skills/*.md`，选择实验 skill 后问答式指导；同名生成不覆盖已有文件 |
| 疑问记录 | 未解决、学习中、已理解 |
| 删除 | 已有删除入口及确认；已实现软删除回收站及恢复；彻底删除需单独确认 |

## 模型与数据处理位置

- 当前本机配置（核对时）：`http://127.0.0.1:18081/v1`，模型 `local-qwen38-gsq`。运行情况应另行检查；配置存在不等于服务可用。
- 内置 ASR：`.venv` + `models/faster-whisper-small`。每次识别通过 Python 子进程加载模型，不是常驻识别服务。首次安装运行 `setup-asr.ps1`。
- 其他本地 ASR：可选 HTTP 接口 `/audio/transcriptions`。默认占位地址为 8000，不代表内置模式需要该端口。
- TTS：`.venv-tts` 内 edge-tts，依赖 ffmpeg；安装入口为 `setup-tts.ps1`。**需联网，朗读文字发送至微软服务，整个应用不能称为完全离线。**
- 持久化：`data/store.json` 存元数据，`data/media/` 存媒体，`skills/` 存实验 skill 文件。

## 限制与待办

- 文本导入前端限制 500 KB，后端资料/笔记上限 200,000 字符；语音问题文件 ≤32 MB。
- 共读当前是简单关键词排序，来源预算约 1800 字符、笔记前 800 字符、选区 500 字符；并非全文知识库检索。模型上下文扩大后，代码预算仍需另行改造。
- 引用存在性校验不等于事实支持性验证；真实实验术语、参数及样例来源仍需人工核对。
- TTS 每次请求上限 2000 字，未实现长回答分段流式播报。
- `ocr_worker.py` 目前是独立、未提交的开发脚本，PDF/OCR 没有接入应用导入流程。
- 仍缺顺畅的逐句视频溯源、充分的迁移/复述练习、完整真实材料验收和工作台集成；可视化备份恢复已有入口。
- 备份须先停止服务，并保存完整 `data/`、`skills/` 和必要配置；Git 代码提交不能代替用户数据备份。
